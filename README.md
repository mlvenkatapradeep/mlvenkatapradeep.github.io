# Pradeep Muvvala — Cybersecurity Portfolio

A GitHub Pages-ready cybersecurity portfolio.

## Publish on GitHub

1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all files from this folder.
3. Open **Settings → Pages** in the repository.
4. Select the `main` branch and `/ (root)` as the source.
5. Save and wait for GitHub Pages to deploy.
6. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/`.
